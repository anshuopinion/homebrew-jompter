# Homebrew tap for Jompter

Install [Jompter](https://jompter.com) — voice dictation, screenshots and screen
recordings turned into clean, AI-ready prompts for Claude Code, Cursor and more.

## Install

```sh
brew install --cask anshuopinion/jompter/jompter
```

(Apple Silicon Macs only, macOS Big Sur or later.)

## Upgrade

```sh
brew upgrade --cask jompter
```

## Uninstall

```sh
brew uninstall --cask --zap jompter
```

Release binaries live at
[anshuopinion/jompter-releases](https://github.com/anshuopinion/jompter-releases).
